## 1. 디자인 원칙

| 원칙 | 설명 | 적용 예시 |
|------|------|-----------|
| 🤗 **부모 친화** | 전문 용어 배제, 일상 언어 사용 | "작업기억" → "기억력", 점수 대신 밴드 |
| 🌿 **따뜻한 신뢰감** | 차분한 자연 톤, 둥근 모서리, 여백 충분 | 소프트 그린 + 베이지 컬러 |
| 📊 **직관적 데이터** | 복잡한 수치 → 시각 요약 | 레이더 차트, 이모지 기반 뱃지 |
| ⚡ **빠른 기록** | 3탭 이내 기록 완료 | 홈에서 원탭 → 기록 시트 |
| 🔒 **안심 설계** | 아이 데이터 보호 강조, 비교 지양 | "상위 20~30%" 밴드, 순위 없음 |

### 3.5 온보딩 인터랙션 상세

| 요소 | 인터랙션 | 세부 |
|------|---------|------|
| 성별 칩 | 탭 → 선택 토글 | 선택 시 #6BBF8A 테두리 + 체크 |
| 기질 Q1 | 단일 선택 라디오 | 선택 시 카드 배경 #E8F5ED |
| 기질 Q2, Q3 | 다중 선택 칩 | 탭 토글, 선택 시 #6BBF8A 배경 + 흰 글씨 |
| "잘 모르겠어요" | 탭 시 다른 칩 전체 해제 | 배타적 선택 |
| 파일 업로드 | 점선 드래그존 탭 | iOS 파일 피커 or 카메라 선택 |
| "안 했어요" | Ghost 버튼 | 즉시 Step 완료 처리 |
| 진행 인디케이터 | 상단 ● ○ ○ | 현재 스텝 강조 |

```
  │    푸시 알림 발송                     │
  │    마일스톤 타임라인에 추가           │
  └──────────────────────────────────────┘
```

### 7.5 발달 추이 인터랙션

| 요소 | 인터랙션 | 세부 |
|------|---------|------|
| 영역 필터 칩 | 탭 토글 → 해당 영역만 표시 | "전체" 시 6개 모두 |
| 그래프 데이터 점 | 탭 → 해당 주 요약 팝업 | 주요 기록 3개 표시 |
| 예측 구간 | 점선 + 옅은 배경 | 탭 → "예측 근거" 모달 |
| 마일스톤 뱃지 | 탭 → 뱃지 상세 | 달성 조건 + 관련 기록 |
| AI 예측 카드 | 정보 표시 | "더 알아보기" → 상세 분석 |

## 부록: 접근성 & 기술 노트

### A. 접근성 가이드라인

| 항목 | 기준 | 적용 |
|------|------|------|
| 색상 대비 | WCAG AA (4.5:1) | 모든 텍스트 |

| 스크린 리더 | 차트에 텍스트 대안 | 레이더/꺾은선 차트 |
| 다크 모드 | v2 대응 예정 | 색상 팔레트 시맨틱 토큰 |
| 폰트 크기 | 시스템 설정 연동 | Dynamic Type 지원 |

### B. 기술 스택 제안

```
  프론트엔드: React Native (iOS + Android)
  차트: react-native-chart-kit / Victory Native
  상태 관리: Zustand
  네비게이션: React Navigation (Stack + Tab)
  애니메이션: Reanimated 3
  바텀시트: @gorhom/bottom-sheet
```
