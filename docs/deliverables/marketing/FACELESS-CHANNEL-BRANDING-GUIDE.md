## 2. 브랜딩 가이드

> 아래 가이드는 **AIFlowHQ**를 기본 채널명으로 가정합니다. 최종 채널명 확정 후 로고 텍스트만 교체하면 됩니다.

### 2.1 색상 팔레트

| 역할 | 색상 | HEX | 용도 |
|------|------|-----|------|
| **Primary** | 일렉트릭 블루 | `#2563EB` | 로고, CTA 버튼, 핵심 강조 |
| **Secondary** | 네온 그린 | `#10B981` | 성공/성장 표현, 어필리에이트 링크 버튼 |
| **Dark BG** | 차콜 블랙 | `#0F172A` | 썸네일 배경, 배너 기본색, 자막 배경 |
| **Light Accent** | 소프트 화이트 | `#F1F5F9` | 텍스트, 자막 글씨, 밝은 UI 요소 |
| **Highlight** | 앰버 오렌지 | `#F59E0B` | 긴급/중요 표시, "NEW" 배지, 숫자 강조 |

**팔레트 설계 원칙**:
- 다크 배경 + 밝은 텍스트 = YouTube 썸네일 CTR 최적화 (검색 결과에서 눈에 띔)
- 블루+그린 조합 = 테크/AI 신뢰감 + 성장/성과 연상
- 오렌지 액센트 = 긴급성/호기심 유발 (숏폼 썸네일 핵심)

```
색상 시각화:
██████ #2563EB (Primary Blue)
██████ #10B981 (Secondary Green)  
██████ #0F172A (Dark Background)
██████ #F1F5F9 (Light Text)
██████ #F59E0B (Highlight Orange)
```

### 2.2 폰트 추천

| 용도 | 폰트명 | 라이선스 | 특징 | 다운로드 |

- 강조 단어: `#F59E0B` (오렌지) 또는 `#10B981` (그린)으로 색상 변경
