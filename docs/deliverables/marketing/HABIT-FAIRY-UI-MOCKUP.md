## 1. 디자인 원칙

### 1.1 핵심 원칙 — 아이 친화적 UX

| # | 원칙 | 설명 | 적용 기준 |
|---|------|------|----------|
| P1 | **큰 터치 영역** | 4~6세 아이의 손가락 정밀도를 고려 | 최소 터치 영역 **48×48dp** (권장 **56×56dp**) |
| P2 | **밝고 따뜻한 색상** | 시각적 안정감 + 흥미 유발 | 노란색/주황색 기반, 파스텔 보조색 |
| P3 | **이모지 + 아이콘 우선** | 미취학 아동은 텍스트보다 시각 기호에 반응 | 모든 미션에 이모지 필수, 텍스트는 보조 |
| P4 | **즉각적 피드백** | 탭 → 애니메이션/소리로 즉시 반응 | 모든 인터랙션에 0.1초 이내 시각/청각 피드백 |
| P5 | **단순한 네비게이션** | 최대 2 depth, 뒤로가기 쉽게 | 한 화면에 1~2가지 액션만 집중 |
| P6 | **부모 영역 분리** | 아이가 실수로 설정 건드리지 않도록 | PIN/패턴 잠금으로 부모 모드 진입 |
| P7 | **격려 중심** | 실패를 강조하지 않고 진전을 칭찬 | 미완료 미션에 ❌ 대신 빈 별(☆) 사용 |

### 3.2 컴포넌트 상세

| 영역 | 컴포넌트 | 스타일 | 동작 |
|------|----------|--------|------|

| **인사 말풍선** | `FairyMessage` | fairy-100 배경, radius 16px, 그림자 | 앱 진입 시 fade-in (0.3s), 매번 AI 생성 |

### 3.3 인터랙션 설명

| 액션 | 트리거 | 반응 | 애니메이션 |
|------|--------|------|-----------|
| **미션 카드 탭** | 미완료 카드 탭 | 미션 실행 화면 이동 | 카드 scale(0.95) → 화면 slide-right |
| **완료 카드 탭** | 완료 카드 탭 | 결과 요약 바텀시트 | 바텀시트 slide-up |
| **요정 캐릭터 탭** | 캐릭터 영역 탭 | 랜덤 응원 메시지 | 요정 jump + 별 파티클 3~5개 |
| **별 카운터 탭** | 별 뱃지 탭 | 별 히스토리 바텀시트 | bounce + 바텀시트 |
| **미션 리스트 스크롤** | 위/아래 스와이프 | 리스트 스크롤 | 자연스러운 관성 스크롤 |

### 6.4 컴포넌트 상세

| 영역 | 컴포넌트 | 스타일 | 동작 |
|------|----------|--------|------|
| **헤더** | `DashboardHeader` | 아이 이름 + 기간 | "아이모드" 탭 → PIN 없이 아이 화면 |
| **달성률 차트** | `CompletionChart` (Recharts PieChart) | 도넛형, 160×160px | 진입 시 0→78% 카운트업 (0.8s) |
| **막대 그래프** | `MissionStatsChart` (Recharts BarChart) | 수평 바, 미션별 | 진입 시 좌→우 grow (0.5s, stagger) |
| **주간 리포트** | `WeeklyReportCard` | parent-card 카드 | 매주 일요일 자동 생성, AI 분석 포함 |
| **미션 추가** | `MissionEditorModal` | 바텀시트 모달 | 입력값 변경 시 AI 설명 실시간 생성 |
| **설정 톱니** | `SettingsButton` | 48×48px, gray-600 | 설정 화면 이동 (알림/결제/계정) |

### 6.5 인터랙션 설명

| 액션 | 트리거 | 반응 | 애니메이션 |
|------|--------|------|-----------|
| **대시보드 진입** | 하단 탭 + PIN | 데이터 로드 + 차트 렌더 | 차트 카운트업 + 바 grow |
| **기간 변경** | 주간 스와이프 좌/우 | 이전/다음 주 데이터 로드 | 슬라이드 전환 |
| **막대 그래프 탭** | 개별 바 탭 | 미션 상세 바텀시트 | 바 하이라이트 + 시트 slide-up |
| **미션 추가** | "+" 버튼 탭 | 에디터 모달 오픈 | 바텀시트 slide-up |
| **미션 이름 입력** | 텍스트 입력 후 0.5초 | AI 설명 자동 생성 | 설명 영역 fade-in + 타이핑 효과 |
| **아이모드 전환** | "← 아이모드" 탭 | PIN 없이 아이 화면 | 부모→아이 slide 전환 |
| **리포트 공유** | 리포트 카드 공유 버튼 | 이미지 생성 → 공유 시트 | 카드 캡처 → 시스템 공유 |

### 7.2 화면 전환 애니메이션

| 전환 | 방향 | 애니메이션 | 시간 |
|------|------|-----------|------|
| 홈 → 미션 실행 | forward | slide-left + fade | 0.3s ease-out |
| 미션 실행 → 별 획득 | overlay | scale-up + confetti | 0.5s spring |
| 별 획득 → 홈 | dismiss | fade-out + slide-down | 0.3s ease-in |
| 홈 → 꾸미기 | tab-switch | slide-left (탭 인디케이터) | 0.25s ease |
| 홈 → 대시보드 | tab-switch + PIN | PIN 오버레이 → slide-left | PIN 후 0.25s |
| 대시보드 → 아이모드 | backward | slide-right | 0.25s ease |
| 모달/바텀시트 | overlay | slide-up + backdrop blur | 0.3s ease-out |

## 8. 접근성 및 아동 안전 UX

### 8.1 접근성 기준

| 항목 | 기준 | 적용 |
|------|------|------|
| **터치 영역** | 최소 48×48dp | 모든 인터랙티브 요소 |
| **색상 대비** | WCAG AA (4.5:1) | 텍스트/배경 조합 |
| **텍스트 크기** | 최소 16px (부모), 20px (아이) | 전체 텍스트 |
| **대체 텍스트** | 모든 이모지/아이콘에 aria-label | 스크린리더 호환 |
| **모션 축소** | `prefers-reduced-motion` 대응 | 애니메이션 off 옵션 |
| **방향** | 세로 고정 (portrait-only) | PWA orientation 설정 |

### 8.2 아동 안전 UX 가이드라인

| 항목 | 구현 방법 |
|------|----------|
| **부모 영역 분리** | 대시보드/설정 → PIN 4자리 잠금 (패턴 잠금 대안) |
| **외부 링크 차단** | 아이 모드에서 외부 URL 접근 불가 |
| **광고 없음** | 전면 광고, 배너 광고 일체 없음 |
| **인앱 구매 차단** | 아이 모드에서 결제 진입 불가 (부모 모드 only) |
| **사용 시간 제한** | 부모 설정: 일일 최대 사용 시간 (기본 30분) |
| **실패 비표현** | ❌/실패 UI 없음, 미완료는 빈 별(☆)로 표시 |
| **AI 안전** | 자유 텍스트 입력 없음, 선택지 기반 인터랙션 |
| **데이터 최소 수집** | 아이 이름 + 생년월일만, 사진/음성 비수집 |
