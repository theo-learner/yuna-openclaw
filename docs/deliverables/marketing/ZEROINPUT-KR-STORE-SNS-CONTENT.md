• 업무 자동화로 시간을 절약하고 싶은 직장인

• ChatGPT, Claude는 있는데 "제대로" 써본 적 없는 분

🎁 무료로 받으실 수 있는 것:
→ 실제 직장인들이 검증한 프롬프트 10개
→ 즉시 복사해서 쓸 수 있는 형식 (이메일, 보고서, 기획안 등)
→ 각 프롬프트별 사용 팁 + 예제

📊 평균 절약 시간: 주 5시간 (월 20시간) = 연간 240시간

**태그:** #AI프롬프트 #업무자동화 #시간절약 #ChatGPT #직장인팁
