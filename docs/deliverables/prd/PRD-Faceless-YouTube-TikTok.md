## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| **목표** | AI 생성 Faceless 콘텐츠 채널 운영, 3~6개월 내 수익화 |
| **CEO 투입 시간** | 주 2~3시간 (방향 검토, 최종 승인) |
| **자동화 범위** | 대본·편집·자막·썸네일·업로드 — AI 에이전트가 80%+ 처리 |
| **6개월 수익 목표** | 월 $2,000 (광고+어필리에이트+디지털 프로덕트 합산) |

### 핵심 원칙

1. **AI as Tool, Not Entire Process** — YouTube 2025.07 정책 변경으로, AI가 전 제작 과정을 담당하는 "AI slop"은 수익화 제외 대상. 반드시 인간 창의성(기획·큐레이션·인사이트)을 넣어야 한다.
2. **멀티 플랫폼 동시 배포** — 하나의 콘텐츠를 YouTube Shorts + TikTok + Instagram Reels로 리포맷.
3. **최소 비용 시작** — 월 $30~50 이내에서 출발, 수익 발생 후 확장.

## 2. 니치 선정

### 2.1 추천 니치: "AI 자동화 & 생산성"

**선정 이유:**
- 우리 팀이 AI 에이전트(OpenClaw) 운영 경험을 실제로 보유 → 진정성 있는 콘텐츠 가능
- CPM $8~15 (Tech/Productivity 니치 평균) — 일반 엔터테인먼트($2~4) 대비 3~5x 높음
- B2B 어필리에이트 연계 용이 (SaaS 도구 추천 → 높은 커미션)
- 검색 수요 지속 증가 (Google Trends "AI tools" 24개월 연속 상승)

### 2.2 타겟 시청자 페르소나

| 페르소나 | 설명 |
|----------|------|
| **주니어 직장인 (25~35)** | 업무 자동화에 관심, 프롬프트 엔지니어링 배우고 싶음 |
| **1인 창업자 / 프리랜서** | AI 도구로 인건비 절감, 생산성 10x 달성 욕구 |
| **사이드 프로젝트 빌더** | AI로 콘텐츠/앱/자동화 만들어 부수입 창출 희망 |

**언어 전략**: 영어 우선 (글로벌 시장 = 더 큰 CPM + 구독 풀). 한국어 버전은 Phase 2에서 검토.

### 2.3 경쟁 채널 분석 기준

분석 대상 채널 선정 시 아래 기준 활용:

| 지표 | 벤치마크 |
|------|----------|
| 구독자 수 | 10K~500K (달성 가능 범위) |
| 업로드 빈도 | 주 3회 이상 |
| 평균 조회수 | 영상당 10K+ |
| 콘텐츠 포맷 | Screen recording / Stock + Voiceover / Motion graphics |
| 수익화 방식 | 광고 + 어필리에이트 링크 + 디지털 프로덕트 |

**참고 채널 (벤치마크)**: AI Advantage, Matt Wolfe, Skill Leap AI, The AI Solopreneur 등

## 3. 콘텐츠 전략

### 3.1 포맷 비율

| 포맷 | 비중 | 용도 |
|------|------|------|
| **숏폼 (< 60초)** | 60% | 알고리즘 노출 극대화, 구독자 유입 |
| **미드폼 (3~8분)** | 30% | 광고 수익 + 검색 SEO |
| **롱폼 (10~15분)** | 10% | 고CPM, 멀티 광고 슬롯 (8분+ = mid-roll 가능) |

### 3.2 멀티 플랫폼 전략

```
[원본 롱폼/미드폼 영상]
     ├── YouTube (원본 업로드)
     ├── YouTube Shorts (핵심 클립 추출, 세로 리포맷)
     ├── TikTok (동일 숏폼 + TikTok 트렌드 음악/해시태그)
     └── Instagram Reels (동일 숏폼 + IG 최적화 캡션)
```

- 숏폼은 세로(9:16), 롱/미드폼은 가로(16:9)
- 숏폼에서 바이럴 → 롱폼으로 트래픽 유도 ("Full tutorial on my channel")

### 3.3 주간 업로드 빈도

| 플랫폼 | 주간 목표 |
|--------|----------|
| YouTube 롱/미드폼 | 2편 |
| YouTube Shorts | 5편 |
| TikTok | 5편 (Shorts 재활용 + TikTok 전용 1~2편) |
| Instagram Reels | 3편 (베스트 성과 숏폼 선별) |

**총 주간 콘텐츠**: ~15편 (대부분 숏폼 재활용)

### 3.4 콘텐츠 카테고리 (시리즈화)

| 시리즈 | 설명 | 포맷 |
|--------|------|------|
| **🛠 AI Tool Review** | 신규 AI 도구 튜토리얼/리뷰 | 미드폼 + 숏폼 클립 |
| **⚡ 60-Second AI Hack** | 즉시 적용 가능한 AI 팁 | 숏폼 전용 |
| **🔄 Workflow Automation** | 실제 자동화 구축 과정 (스크린 녹화) | 롱폼 |
| **📊 AI News Weekly** | 주간 AI 뉴스 요약 | 미드폼 |
| **🆚 Tool vs Tool** | AI 도구 비교 (ChatGPT vs Claude 등) | 미드폼 |

## 4. 제작 파이프라인 (AI 자동화)

### 4.1 워크플로우 개요

```
[1] 주제 선정 ──→ [2] 대본 생성 ──→ [3] 보이스오버 ──→ [4] 영상 제작
  (CEO 승인)     (AI + 인간 편집)   (AI TTS)        (AI + 편집)
                                                        │
[7] 분석/최적화 ←── [6] 업로드 ←── [5] 썸네일/자막
  (CEO 리뷰)       (자동화)       (AI 생성)
```

### 4.2 단계별 도구 및 프로세스

#### Step 1: 주제 선정 (CEO 10분/주)
- AI 에이전트가 트렌딩 AI 뉴스/도구 리스트 제안
- CEO가 주간 콘텐츠 캘린더 승인 (5분)
- 키워드 리서치: vidIQ / TubeBuddy 무료 플랜

#### Step 2: 대본 생성 (AI 에이전트)
- AI 에이전트(Claude/GPT)가 SEO 최적화 대본 초안 작성
- **인간 터치 필수**: CEO 또는 에이전트가 개인 경험·인사이트 추가
- 대본 구조: Hook (5초) → Problem → Solution → CTA

#### Step 3: 보이스오버 (AI TTS)
- **ElevenLabs** — $5/월 Starter 플랜 (30분 생성)
- 일관된 목소리 캐릭터 유지 (브랜드 보이스 클로닝)
- 대안: Edge TTS (무료), Hume AI ($3/월)

#### Step 4: 영상 제작
- **Screen Recording**: OBS Studio (무료) — 튜토리얼용
- **Stock Footage**: Pexels / Pixabay (무료)
- **AI 영상 생성**: InVideo AI ($25/월) — 대본 → 영상 자동 생성
- **모션 그래픽**: Canva Pro ($13/월) — 텍스트 애니메이션, 트랜지션

#### Step 5: 편집 & 자막
- **자동 자막**: CapCut (무료) — 숏폼 자막 자동 생성
- **편집 자동화**: CapCut / DaVinci Resolve (무료)
- **썸네일**: Canva Pro + AI 이미지 (DALL-E / Midjourney)

#### Step 6: 업로드
- **예약 업로드**: YouTube Studio 네이티브
- **TikTok/Reels**: Later 또는 Buffer (무료 플랜으로 시작)
- **메타데이터**: AI 에이전트가 제목·설명·태그·해시태그 자동 생성

#### Step 7: 분석 & 최적화 (CEO 30분/주)
- YouTube Analytics 주간 리뷰
- AI 에이전트가 성과 리포트 요약 제공
- 저성과 콘텐츠 패턴 분석 → 다음 주 전략 반영

## 9. 리스크 & 대응

### 9.1 YouTube AI 콘텐츠 정책 (🔴 High Risk)

**현황** (2025.07 시행):
- AI 생성 콘텐츠 의무 공개 (YouTube Studio 체크박스)
- "AI slop" (저품질 대량 생산) → 수익화 제외
- AI를 **도구**로 활용 = 허용. AI가 **전체 제작** = 수익화 불가

**대응 전략**:
- ✅ 모든 영상에 AI disclosure 체크 (투명성)
- ✅ 실제 경험 기반 인사이트 반드시 포함 (차별화)
- ✅ 스크린 녹화 + 실습 시연 = "인간 창의적 입력" 증명
- ✅ 대본에 개인 의견/비교 분석 추가 (단순 정보 나열 X)
- ❌ 절대 하지 말 것: Stock footage + AI 내레이션만으로 구성된 영상

### 9.2 저작권 이슈 (🟡 Medium Risk)

| 리스크 | 대응 |
|--------|------|
| AI 생성 이미지 저작권 | 상업 라이선스 있는 도구만 사용 (Canva Pro, Midjourney 유료) |
| 배경 음악 | YouTube Audio Library (무료·로열티프리) 또는 Epidemic Sound |
| Stock footage | Pexels/Pixabay (CC0 라이선스 확인) |
| AI 보이스 | 클론 보이스 시 타인 음성 사용 금지, 자체 생성 음성만 |
| 리뷰/튜토리얼 스크린샷 | Fair Use 범위 내 사용 (교육 목적 명시) |

### 9.3 알고리즘 변경 리스크 (🟡 Medium Risk)

**대응**:
- 멀티 플랫폼 분산 (YouTube 의존도 < 60%)
- 이메일 뉴스레터로 자체 오디언스 구축 (Beehiiv 무료 플랜)
- 숏폼/롱폼 균형 유지 (한 포맷에 올인 X)

### 9.4 경쟁 과열 (🟡 Medium Risk)

**대응**:
- "실제 사용 경험" = 최대 차별화 (AI 에이전트 직접 운영 팀)
- 니치 세분화: "AI for Solo Entrepreneurs" 등 하위 니치
- 일관된 업로드로 알고리즘 신뢰도 확보

### 9.5 번아웃 / 지속성 (🟢 Low Risk — 자동화로 완화)

- 배치 제작: 주 1회 집중 제작 → 주간 예약 배포
- AI 자동화 파이프라인이 반복 작업 80% 제거
- CEO 시간 주 2~3시간 한도 엄격 준수

## 10. 실행 계획 (Week 1~4)

### Week 1: 채널 세팅
- [ ] 채널명 확정 + 브랜딩 (로고, 배너, 색상 팔레트)
- [ ] YouTube / TikTok / Instagram 계정 생성
- [ ] ElevenLabs 보이스 캐릭터 생성 + 테스트
- [ ] 콘텐츠 캘린더 템플릿 생성
- [ ] 첫 5개 영상 주제 확정

### Week 2: 파이프라인 테스트
- [ ] 첫 롱폼 1편 + 숏폼 3편 제작 (end-to-end 파이프라인 검증)
- [ ] 업로드 → 메타데이터 최적화 프로세스 확립
- [ ] 썸네일 A/B 테스트 템플릿 3종 제작

### Week 3~4: 본격 운영
- [ ] 주간 5 숏폼 + 2 미드/롱폼 업로드 시작
- [ ] 어필리에이트 프로그램 가입 (ElevenLabs, Canva, Notion 등)
- [ ] 디지털 프로덕트 제작 시작 (프롬프트 팩)
- [ ] 주간 성과 리뷰 루틴 확립
