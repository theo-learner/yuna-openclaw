## 1. 프로덕트 정의

### 1.1 서비스 개요

| 항목 | 내용 |
|------|------|
| **서비스명** | PrintPlay (프린트플레이) |
| **한줄 소개** | "세상에 하나뿐인, 우리 아이만의 활동지" — AI가 아이 맞춤형 활동지를 무한 생성 |
| **핵심 가치** | 워킹맘/대디가 퇴근 후 30초 만에 아이 맞춤 활동지를 뽑아줄 수 있는 서비스 |
| **타겟** | 4~6세 아이의 부모 (워킹맘/워킹대디), 소득 월 450~650만원, 교육 콘텐츠 월 1~3만원 지출 의향 |
| **플랫폼** | 웹 (모바일 최적화) + PDF 다운로드 |
| **판매 채널** | 크티(CTEE) + 네이버 스마트스토어 + 자체 웹사이트 |

### 1.2 프라이머리 페르소나

> **김지은** (36세), 맞벌이 워킹맘, 5세 아들 "시우"  
> - 평일 저녁 7시 퇴근, 아이와 30분 놀아줄 콘텐츠가 항상 필요  
> - 네이버에서 "유아 활동지 무료" 매주 검색  
> - 프린터 있음, PDF 다운로드 → 인쇄에 익숙  
> - **페인 포인트**: "같은 활동지 반복 → 아이가 흥미 없음" / "구매해도 난이도가 안 맞음"  
> - **WTP**: 월 1~3만원  

### 1.3 경쟁 환경

| 경쟁사 | 가격 | 약점 (우리 기회) |
|--------|------|-----------------|
| 핀덴 | 월 9,900원 | 정형화된 콘텐츠, AI 맞춤 없음 |
| 한글이야호 | 월 14,900원 | 영상 중심, 프린트 활동지 부족 |
| 네이버 블로그 무료 활동지 | 무료 | 난이도 조절 불가, 종류 한정 |
| Twinkl (해외) | $7.49/월 | 영어 콘텐츠, 한국 커리큘럼 미반영 |

**PrintPlay 차별점**:
- ✅ **AI 무한 생성**: 매번 새로운 활동지 (같은 주제라도 다른 내용)
- ✅ **아이 맞춤**: 이름 + 나이 입력 → 난이도 자동 조절
- ✅ **한국 특화**: 한글/숫자/영어 + 한국 시즌별(설날, 추석, 어린이날) 콘텐츠
- ✅ **마진 90%+**: 재고 없음, 디지털 상품

### 2.3 카테고리별 활동지 상세

| 카테고리 | 난이도별 변화 (4세 → 5세 → 6세) | AI 생성 방식 |
|----------|-------------------------------|-------------|
| 🎨 **색칠하기** | 큰 도형 → 동물/탈것 → 세밀한 풍경 | AI 이미지 생성 → 선화(Line Art) 변환 |
| 🌀 **미로 찾기** | 3×3 단순 → 5×5 중간 → 8×8 복잡 | 알고리즘 미로 생성 + AI 테마 일러스트 |
| 🔢 **점잇기** | 1~10 → 1~20 → 1~50 | 알고리즘 포인트 배치 + AI 완성 그림 |
| ㄱ **한글 연습** | 자음 따라쓰기 → 모음 조합 → 단어 쓰기 | 템플릿 기반 + AI 예시 단어/문장 생성 |
| 🔟 **숫자 연습** | 1~5 쓰기 → 1~10 + 세기 → 덧셈뺄셈 기초 | 템플릿 기반 + AI 문제 생성 |
| 🔤 **영어 연습** | A~F 대문자 → 전체 알파벳 → 단어 쓰기 | 템플릿 기반 + AI 예시 단어 생성 |

## 3. 기술 스택

### 3.1 전체 아키텍처

```
[사용자 브라우저] ←→ [Cloudflare Pages / Vercel]
                           ↓
                    [Next.js 프론트엔드]
                           ↓
                    [Next.js API Routes / Serverless]
                     ↙     ↓      ↘
            [AI 이미지]  [PDF 생성]  [결제]
            (DALL-E 3    (Puppeteer/  (크티 API /
             or SDXL)    jsPDF)       토스페이먼츠)
                           ↓
                    [Supabase (DB + Auth + Storage)]
```

### 3.2 기술 스택 상세

| 영역 | 기술 | 선택 이유 |
|------|------|----------|
| **프론트엔드** | Next.js 14 + Tailwind CSS | SSR/SSG 지원, 모바일 최적화 용이, 빠른 개발 |
| **백엔드** | Next.js API Routes (Serverless) | 별도 서버 불필요, 비용 최소화 |
| **DB + Auth** | Supabase (PostgreSQL + Auth) | 무료 티어 충분, Google/카카오 소셜 로그인 |
| **파일 저장** | Supabase Storage 또는 Cloudflare R2 | PDF 파일 저장, CDN 배포 |
| **호스팅** | Vercel (Free → Pro) 또는 Cloudflare Pages | 무료 시작, 자동 배포, 글로벌 CDN |
| **AI 이미지 생성** | OpenAI DALL-E 3 (1차) / SDXL via Replicate (대안) | 활동지 품질 보장, API 호출 간편 |
| **PDF 생성** | Puppeteer (서버사이드) + React-PDF | HTML→PDF 변환, 복잡한 레이아웃 지원 |
| **결제** | 토스페이먼츠 (자체 웹) + 크티 내장 결제 + 스마트스토어 | 다채널 결제 커버 |
| **분석** | Google Analytics 4 + Mixpanel (Free) | 전환 퍼널 추적, 무료 |
| **마케팅** | Mailchimp (Free) 또는 스티비 | 이메일 뉴스레터, 무료 1,000명까지 |

### 3.3 AI 활동지 생성 파이프라인

```
[사용자 요청]
  ↓ (카테고리 + 나이 + 이름)
[프롬프트 엔지니어링 모듈]
  ↓ (카테고리별 최적화된 프롬프트)
[AI 이미지 생성 API]
  ↓ (DALL-E 3: 색칠하기, 미로 테마 등)
[후처리 모듈]
  ↓ (색칠→선화 변환, 미로→경로 생성, 한글/숫자→템플릿 합성)
[PDF 렌더링]
  ↓ (A4 레이아웃, 이름 워터마크, 페이지 번호)
[PDF 저장 & 다운로드 URL 발급]
```

**카테고리별 생성 전략**:

| 카테고리 | AI 사용 | 알고리즘 사용 | 비고 |
|----------|---------|-------------|------|
| 색칠하기 | DALL-E 3 → 선화 변환 | - | Canny Edge Detection 후처리 |
| 미로 | 테마 일러스트 | DFS/Kruskal 미로 생성 | 알고리즘이 핵심, AI는 꾸미기 |
| 점잇기 | 완성 그림 힌트 | 좌표 기반 점 배치 | 알고리즘이 핵심 |
| 한글/숫자/영어 | 예시 단어/문제 생성 (GPT-4o) | 글씨 연습 템플릿 | 템플릿 기반, AI는 콘텐츠 생성 |

### 3.4 AI API 비용 추정 (활동지 1건 기준)

| API | 단가 | 활동지 1건당 호출 | 건당 비용 |
|-----|------|-----------------|----------|
| DALL-E 3 (1024×1024, Standard) | $0.04/장 | 1~2회 | $0.04~0.08 (약 55~110원) |
| GPT-4o Mini (텍스트 생성) | $0.15/1M input tokens | 1회 (~500 tokens) | $0.0001 (약 0.1원) |
| **합계** | | | **약 55~110원/건** |

> ⚡ **핵심 인사이트**: 활동지 1건 생성 원가 ~100원, 단품 3,900원 판매 시 **원가율 2.5%**, 마진 97%+

## 8. 부록

### 8.1 마케팅 메시지 가이드

**✅ Do (이렇게 말하기)**:
- "세상에 하나뿐인 우리 아이만의 활동지"
- "시우의 한글 연습장" (개인화 강조)
- "매일 새로운 활동지가 무한으로!"
- "프린터만 있으면 5초 만에 출력"
- "엄마표 학습지, 이제 AI가 도와줘요"

**❌ Don't (이렇게 말하지 않기)**:
- "AI가 자동 생성합니다" (기계적 느낌)
- "무한 생성" (과장 느낌) → "매일 새로운"으로 대체
- 기술적 용어 (DALL-E, GPT 등) 노출 금지
