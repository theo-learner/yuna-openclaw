## 사용법

1. 프롬프트를 **그대로 복사**하세요
2. `[대괄호]` 안의 내용만 **본인 상황에 맞게** 수정하세요
3. ChatGPT, Claude, Gemini 등 **아무 AI에 붙여넣기**하세요
4. 결과물이 80%만 맞으면, **수정 요청**을 추가로 하세요

**💡 팁:** GPT-4, Claude 3.5 이상 모델에서 가장 좋은 결과를 얻을 수 있습니다. 무료 모델에서도 작동하지만, 유료 모델이 확실히 결과가 다릅니다.

## 프롬프트 #1: 블로그 글 한 방에 완성하기

### 용도
블로그, 브런치, 네이버 블로그 등에 올릴 전문성 있는 글을 빠르게 작성

### 프롬프트:
```
당신은 전문 콘텐츠 전략가이자 SEO 글쓰기 전문가입니다. [주제]에 대한 블로그 글을 작성해주세요.

요구사항:
- 타겟 독자: [독자층 — 예: IT 업계 주니어 개발자]
- 톤: [전문적/대화체/권위 있는]
- 길이: 2,000-3,000자
- 독자의 시선을 끄는 제목 작성 (숫자 또는 질문형)
- 놀라운 통계나 반직관적 인사이트로 시작
- AIDA 프레임워크 사용 (주의, 흥미, 욕구, 행동)
- SEO 최적화된 소제목 5-7개 (H2 태그)
- 상단에 "핵심 요약" 박스 3가지 포함
- 구체적인 CTA로 마무리
- 이 키워드를 자연스럽게 포함: [키워드1], [키워드2], [키워드3]

마크다운 형식으로 출력해주세요.
```

### 예시:
- **주제:** "신입 개발자를 위한 AI 코딩 도구 활용법"
- **독자:** 경력 1-3년 주니어 개발자
- **키워드:** "AI 코딩 도구," "개발 생산성," "ChatGPT 코딩"

### 기대 효과:
보통 3-4시간 걸리는 블로그 글 초안을 10분 만에 완성. 구조와 SEO가 잡힌 상태에서 시작하니 편집만 하면 됩니다.

## 프롬프트 #2: 회의록 정리의 달인

### 용도
장황한 회의 내용을 액션 아이템 중심으로 깔끔하게 정리

### 프롬프트:
```
다음 회의 내용/녹취록을 구조화된 액션 문서로 변환해주세요.

회의 내용:
"""
[회의 내용 또는 녹취록 붙여넣기]
"""

다음 섹션으로 정리해주세요:

## 회의 요약 (3-5문장)

## 핵심 의사결정 사항
- [결정 내용] — 결정자: [담당자] — 시행일: [날짜]

## 액션 아이템
| # | 업무 | 담당자 | 마감일 | 우선순위 | 의존성 |
|---|------|--------|--------|----------|--------|

## 미결 사항 / 추후 논의 필요
- [질문] — 확인 필요 대상: [담당자]

## 주요 논의 내용
(시간순이 아닌, 주제별로 정리)

## 후속 회의 필요 여부
- 예/아니오 — 제안 일시: — 주요 안건:

규칙:
- 담당자가 불분명하면 [확인 필요]로 표기
- 마감일이 미정이면 맥락에 맞게 제안
- 이전 결정과 모순되는 내용 플래그 처리
- 전체 500자 이내로 정리
```

### 기대 효과:
30분 걸리던 회의록 정리가 2분으로 단축. 팀원에게 바로 공유할 수 있는 깔끔한 문서 완성.

## 프롬프트 #3: 냉정한 편집자

### 용도
작성한 글의 품질을 한 단계 끌어올리는 전문 편집

### 프롬프트:
```
당신은 국내 최고 출판사에서 10년간 일한 편집 전문가입니다. 편집 철학: 모든 문장은 존재 이유가 있어야 합니다.

다음 글을 세 번의 패스로 편집해주세요:

**1차 — 명확성과 구조:**
- 모호한 문장 지적
- 흐름 개선을 위한 순서 변경 제안
- 빠진 연결고리 식별
- 불필요한 단락 표시

**2차 — 간결함과 임팩트:**
- 분량 20-30% 줄이기 (의미 손실 없이)
- 약한 동사를 강한 동사로 교체
- 군더더기 표현 제거 (매우, 정말, 다소, 약간 등)
- 피동형을 능동형으로 변환
- 모든 문장을 더 단단하게

**3차 — 마무리와 톤:**
- 일관된 톤 확인: [원하는 톤]
- 리듬감과 문장 길이 다양화
- 도입부와 마무리 강화
- 구체적 디테일 추가

각 수정 사항에 대해:
- 원문 → 수정문 표시
- 수정 이유 간략 설명

세 번의 패스 후, 최종 클린 버전을 제공해주세요.

편집할 글:
"""
[글 붙여넣기]
"""
```

### 기대 효과:
마치 전문 편집자에게 의뢰한 것 같은 퀄리티. 보고서, 기획안, 블로그 글 등 모든 글의 완성도가 올라갑니다.

## 프롬프트 #4: 코드 리뷰 파트너

### 용도
시니어 개발자처럼 꼼꼼하게 코드 리뷰

### 프롬프트:
```
다음 코드를 시니어 엔지니어로서 철저하게 리뷰해주세요. 건설적이되 솔직하게 피드백해주세요.

```[언어]
[코드 붙여넣기]
```

리뷰 기준 (각각 1-10점 평가):

1. **정확성** — 의도한 대로 동작하는가?
2. **가독성** — 다른 개발자가 60초 안에 이해할 수 있는가?
3. **성능** — 명백한 병목이나 O(n²) 함정이 있는가?
4. **보안** — 입력 검증, 인젝션 위험, 인증 문제?
5. **에러 처리** — 엣지 케이스, 정상적 실패 처리?
6. **DRY/SOLID** — 반복 로직, 단일 책임 위반?
7. **테스트 용이성** — 테스트 가능한가? 핵심 테스트 케이스 제안

발견한 문제별로:
- 🔴 심각 (반드시 수정)
- 🟡 개선 (수정 권장)
- 🟢 사소 (있으면 좋음)

각 이슈에 대해:
- 해당 라인/섹션
- 문제점
- 수정 방법 (코드 포함)
- 왜 중요한지

마지막에 전체 평가와 가장 임팩트 큰 개선 1가지를 알려주세요.
```

### 기대 효과:
시니어 개발자와 페어 프로그래밍하는 것처럼 구체적이고 교육적인 코드 리뷰. 혼자 개발할 때 특히 유용합니다.

## 프롬프트 #5: 리서치 요약 보고서

### 용도
복잡한 주제를 빠르게 파악하고 의사결정에 활용

### 프롬프트:
```
[주제]에 대해 깊이 있게 이해해야 합니다. 복잡한 정보를 명확한 인사이트로 정리하는 리서치 분석가 역할을 해주세요.

현재 지식 수준: [초급/중급/고급]
리서치 목적: [의사결정/보고서 작성/프레젠테이션/기획 등]

다음 구조로 정리해주세요:

1. **핵심 요약** (5문장 이내)
   - 이것이 무엇이고, 왜 중요하고, 현재 상태

2. **핵심 개념** (전문 용어는 쉽게 풀어서)
   | 개념 | 쉬운 설명 | 왜 중요한가 |
   |------|-----------|-------------|

3. **현재 트렌드** (2026년 기준)
   - 지금 잘 작동하는 것
   - 새롭게 떠오르는 것
   - 쇠퇴하고 있는 것

4. **주요 플레이어 / 전문가**
   - 팔로우할 만한 기업/전문가 TOP 5
   - 핵심 자료/매체

5. **상반된 시각**
   - 관점 A: [주장 + 근거]
   - 관점 B: [반론 + 근거]
   - 종합 판단: [어느 쪽이 더 근거가 있는가]

6. **실질적 시사점**
   - "그래서 뭐?" — [나의 맥락]에서 이것이 의미하는 바
   - 이 리서치를 바탕으로 할 수 있는 3가지 행동

7. **추천 자료** (5가지)
   - [제목] — 추천 이유 (각 1문장)
```

### 기대 효과:
8-10시간 분량의 리서치를 10분 만에 정리. 의사결정에 바로 활용할 수 있는 구조화된 리서치 브리프.

## 프롬프트 #6: 비즈니스 모델 평가

### 용도
사업 아이디어의 가능성을 체계적으로 진단

### 프롬프트:
```
다음 사업 아이디어를 체계적 프레임워크로 평가해주세요.

**사업 아이디어:** [2-3문장으로 설명]
**타겟 시장:** [누구]
**수익 모델:** [어떻게 돈을 버는가]
**내가 가진 자원:** [시간, 자금, 기술, 팀]

다음 기준으로 각각 1-10점 평가 (근거 포함):

1. **시장 규모** — 이 시장이 충분히 큰가?
2. **문제의 심각도** — 비타민인가, 진통제인가?
3. **지불 의향** — 실제로 돈을 낼 것인가? 근거?
4. **경쟁** — 누가 이미 하고 있는가? 진입장벽은?
5. **실행 난이도** — 만들고 운영하기 얼마나 어려운가?
6. **수익까지의 시간** — 얼마나 빨리 매출이 발생하나?
7. **확장성** — 비용 비례 없이 성장 가능한가?
8. **경쟁 우위** — 남이 없고 나만 가진 것은?
9. **유닛 이코노믹스** — 고객획득비, 고객생애가치, 마진이 맞는가?
10. **개인 적합성** — 내 역량과 관심에 맞는가?

그리고 다음을 제공해주세요:
- **종합 점수** (/100) + 등급: 🟢 진행 | 🟡 신중하게 | 🔴 재고 필요
- **TOP 3 리스크** + 각각 검증/완화 방법
- **최소 비용 검증법** — 10만원 이내, 1주일 이내로 수요를 확인하는 방법
- **솔직한 1단락 평가**
```

### 기대 효과:
확증 편향 없이 사업 아이디어를 객관적으로 평가. "최소 비용 검증법"으로 아이디어를 빠르게 테스트할 수 있습니다.

## 프롬프트 #7: 브레인스토밍 폭발기

### 용도
40개 아이디어를 체계적으로 생성하고 우선순위 결정

### 프롬프트:
```
[과제/프로젝트]에 대한 창의적 아이디어가 필요합니다. 체계적 브레인스토밍 세션을 진행해주세요.

**과제:** [문제 또는 기회 설명]
**제약 조건:** [예산, 시간, 자원, 규칙]
**타겟 대상:** [누구]
**기존에 시도한 것:** [이미 있는 접근법]

4라운드로 아이디어를 생성해주세요:

### 라운드 1: 당연한 해결책 (10개)
[누구나 처음 떠올리는 아이디어 — 먼저 쏟아내기]

### 라운드 2: 다른 업계에서 훔치기 (10개)
[다른 산업에서는 비슷한 문제를 어떻게 해결하나?]
- "쿠팡/넷플릭스/당근마켓/카카오라면 어떻게 할까?"

### 라운드 3: 제약 조건 해제 (10개)
[예산/시간/자원이 무한하다면 무엇을 할까?]
[그다음: 현재 제약 안에서 이를 근사하게 구현하는 법]

### 라운드 4: 황당함 → 천재적 (10개)
[일부러 엉뚱한 아이디어로 시작, 각각에서 핵심 아이디어 추출]

### 평가 매트릭스
| # | 아이디어 | 임팩트(1-5) | 실현가능성(1-5) | 참신함(1-5) | 총점 |
|---|----------|-------------|----------------|-------------|------|

### TOP 3 추천
1. **빠른 성과:** [실현가능성 높음 + 적당한 임팩트]
2. **큰 베팅:** [높은 임팩트, 더 많은 자원 필요]
3. **다크호스:** [비전통적이지만 돌파구가 될 수 있음]
```

### 기대 효과:
사고 방식별로 정리된 40개 아이디어 + 우선순위 매트릭스. 팀 회의에서 "좋은 아이디어가 없다"는 말이 사라집니다.

## 프롬프트 #8: 설득력 있는 카피 작성

### 용도
랜딩페이지, 광고, 상품 설명 등 전환율 높은 카피

### 프롬프트:
```
PAS 프레임워크(문제-자극-해결)를 사용하여 [자산 유형]의 전환 최적화 카피를 작성해주세요.

제품/서비스: [제품명]
타겟 고객: [상세 페르소나 — 나이, 역할, 고민, 원하는 것]
고유 판매 포인트: [USP]
가격: [가격]
주요 경쟁사: [경쟁사]

자산 유형: [하나 선택]
□ 랜딩페이지 히어로 섹션 + 3개 기능 섹션
□ 세일즈 페이지 (장문, 2,000자 이상)
□ 상품 설명 (500자)
□ 광고 카피 (페이스북/구글 — 3가지 변형)

요구사항:
- 제품이 아니라 고객의 #1 고민으로 시작
- 구체적 숫자와 성과 사용 ("생산성 향상" 말고 → "주 12시간 절약")
- 사회적 증거 요소 최소 2개 포함
- 카피 안에서 최대 반론을 미리 해소
- 테스트 가능한 헤드라인 3개
- 긴급성을 주되 저렴해 보이지 않는 CTA 한 줄
```

### 기대 효과:

### Level 3: "와우" 버전 (접근 방식 자체를 재구상)
