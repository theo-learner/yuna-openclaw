## 프롬프트 #1: 전문 블로그 글 생성기

### 프롬프트:
```
당신은 전문 콘텐츠 전략가이자 SEO 글쓰기 전문가입니다. [주제]에 대한 블로그 글을 작성해주세요.

요구사항:
- 타겟 독자: [독자층]
- 톤: [전문적/대화체/권위 있는]
- 길이: 2,000-3,000자
- 독자의 시선을 끄는 제목 (숫자 또는 파워 워드 포함)
- 놀라운 통계나 반직관적 인사이트로 시작
- AIDA 프레임워크 사용 (주의→흥미→욕구→행동)
- SEO 최적화된 소제목 5-7개 (H2)
- 상단에 "핵심 요약" 3가지 포함
- 구체적인 CTA로 마무리
- 이 키워드를 자연스럽게 포함: [키워드1], [키워드2], [키워드3]

마크다운 형식으로 출력해주세요.
```

### 사용 예시:
- **주제:** "2026년 신입 개발자를 위한 AI 코딩 도구 활용법"
- **독자:** 경력 1-3년 주니어 개발자
- **톤:** 대화체
- **키워드:** "AI 코딩 도구," "개발 생산성," "ChatGPT 코딩"

### 예상 결과:
보통 3-4시간 걸리는 블로그 글 초안이 10분 만에 완성됩니다. SEO 구조와 독자 유인 요소가 잡혀 있어서 편집만 하면 바로 발행 가능합니다. 네이버 블로그, 브런치, 티스토리 등에 바로 활용 가능.

## 프롬프트 #2: 이메일 시퀀스 설계자

### 프롬프트:
```
[비즈니스 유형]을 위한 [숫자]개의 환영 이메일 시퀀스를 설계해주세요.

각 이메일에 대해 다음을 제공하세요:
1. 제목 (+ A/B 테스트용 대안 2개)
2. 미리보기 텍스트 (20-30자)
3. 본문 전체
4. CTA 버튼 텍스트
5. 발송 타이밍 (이전 이메일로부터의 간격)

맥락:
- 제품/서비스: [제품]
- 타겟 독자: [독자층]
- 시퀀스의 주요 목표: [목표 — 예: 무료 체험에서 유료 전환]
- 브랜드 보이스: [보이스 — 예: 친근한 전문가, 전문 용어 자제]
- 해소해야 할 주요 반론: [반론1], [반론2], [반론3]

다음 구조를 사용하세요:
- 이메일 1: 환영 + 즉각적인 가치 전달
- 이메일 2: 스토리 기반 문제 심화
- 이메일 3: 사회적 증거 + 사례 연구
- 이메일 4: 반론 해소
- 이메일 5: 긴급성 + 최종 CTA

각 이메일은 300자 이내로. 마케터가 아닌 사람처럼 자연스럽게 써주세요.
```

### 사용 예시:
- **비즈니스:** 온라인 교육 플랫폼 (클래스101, 패스트캠퍼스 등)
- **제품:** "AI 마스터 클래스" (₩249,000)
- **목표:** 무료 미니 강좌 수강생을 유료 등록으로 전환
- **반론:** "너무 비싸다," "기술적이지 않다," "시간이 없다"

### 예상 결과:
제목, 본문, 타이밍까지 완성된 5개 이메일 시퀀스. 스티비(Stibee), 메일침프 등 이메일 마케팅 플랫폼에 바로 적용 가능합니다.

## 프롬프트 #3: 콘텐츠 리퍼포징 머신

### 프롬프트:
```
아래 콘텐츠를 여러 플랫폼에 맞게 변환해주세요. 핵심 메시지는 유지하되 각 플랫폼의 톤에 맞게 조정해주세요.

원본 콘텐츠:
"""
[블로그 글, 뉴스레터, 영상 대본 등 붙여넣기]
"""

다음 버전을 모두 만들어주세요:

1. **X(트위터) 스레드** (8-12개 트윗)
   - 스크롤을 멈추게 하는 훅 트윗
   - 각 트윗이 독립적이면서도 스토리를 이어가기
   - CTA + 스레드 요약으로 마무리

2. **링크드인 게시글** (600-750자)
   - 전문적이지만 개인적인 톤
   - 강렬한 첫 줄로 시작
   - 가독성을 위해 줄바꿈 활용
   - 댓글을 유도하는 질문으로 마무리

3. **인스타그램 캡션** (1,100자 이내)
   - 몰입되는 첫 줄 ("안녕하세요" 금지)
   - 스토리텔링 접근
   - 관련 해시태그 5-10개
   - 저장/공유 CTA

4. **유튜브 쇼츠/틱톡 대본** (45-60초)
   - 패턴 인터럽트 오프닝 (처음 3초가 승부)
   - 대화체, 에너지 넘치는 톤
   - 참여를 유도하는 훅으로 마무리

5. **뉴스레터 스니펫** (200-300자)
   - 제목 + 미리보기 텍스트
   - 핵심 인사이트 1개 + CTA 1개
```

### 사용 예시:
2,000자짜리 "재택근무 생산성 팁" 블로그 글을 붙여넣으세요.

### 예상 결과:
하나의 콘텐츠에서 5개 플랫폼 최적화 버전이 생성됩니다. 콘텐츠 하나당 3-4시간 절약. 브런치 글 하나를 써놓으면 인스타, 링크드인, X까지 한 번에 커버 가능.

## 프롬프트 #4: 냉정한 편집자

### 프롬프트:
```
당신은 국내 최고 출판사에서 10년간 편집장으로 일한 전문 편집자입니다. 편집 철학: 모든 문장은 존재 이유가 있어야 합니다.

다음 글을 세 번의 패스로 편집해주세요:

**1차 — 명확성과 구조:**
- 모호한 문장 지적
- 흐름 개선을 위한 순서 변경 제안
- 빠진 연결고리 식별
- 불필요한 단락 표시

**2차 — 간결함과 임팩트:**
- 분량 20-30% 줄이기 (의미 손실 없이)
- 약한 동사를 강한 동사로 교체
- 군더더기 표현 제거 (매우, 정말, 다소, 약간, 각종 등)
- 피동형을 능동형으로 변환
- 모든 문장을 더 단단하게

**3차 — 마무리와 톤:**
- 일관된 톤 확인: [원하는 톤]
- 리듬감과 문장 길이 다양화
- 도입부와 마무리 강화
- 추상적인 곳에 구체적 디테일 추가

각 수정 사항에 대해:
- 원문 → 수정문 (취소선 형식)
- 수정 이유 간략 설명

세 번의 패스 후, 최종 클린 버전을 제공해주세요.

편집할 글:
"""
[글 붙여넣기]
"""
```

### 사용 예시:
500자 분량의 사업 기획안 초안 또는 브런치 에세이를 붙여넣으세요.

### 예상 결과:
전문 편집자에게 의뢰한 것 같은 품질의 편집본. 20-30% 더 짧고, 훨씬 더 읽기 좋으며, 모든 수정에 이유가 달려 있어 글쓰기 실력 자체가 향상됩니다. 보고서, 기획안, 칼럼 등 어떤 글이든 적용 가능.

## 프롬프트 #5: 전환율 높은 카피라이터

### 프롬프트:
```
PAS 프레임워크(문제-자극-해결)를 사용하여 [자산 유형]의 전환 최적화 카피를 작성해주세요.

제품/서비스: [제품명]
타겟 고객: [상세 페르소나 — 나이, 역할, 고민, 원하는 것]
고유 판매 포인트: [USP]
가격: [가격]
주요 경쟁사: [경쟁사]

자산 유형: [하나 선택]
□ 랜딩페이지 히어로 섹션 + 3개 기능 섹션
□ 세일즈 페이지 (장문, 2,000자 이상)
□ 상품 설명 (500자)
□ 광고 카피 (페이스북/구글/네이버 — 3가지 변형)

요구사항:
- 제품이 아니라 고객의 #1 고민으로 시작
- 구체적 숫자와 성과 사용 ("생산성 향상" ✕ → "주 12시간 절약" ○)
- 사회적 증거 요소 최소 2개 포함
- 카피 안에서 최대 반론을 미리 해소
- 테스트 가능한 헤드라인 3개 작성
- 긴급성을 주되 싸구려 느낌 없는 CTA 한 줄
```

### 사용 예시:
- **제품:** 프로젝트 관리 SaaS (월 ₩29,000)
- **페르소나:** 번아웃 직전의 스타트업 대표, 28-40세
- **USP:** "AI가 팀원 업무량 기반으로 자동 배정"
- **경쟁사:** 노션, 먼데이닷컴
- **자산:** 랜딩페이지

### 예상 결과:
헤드라인, 본문, 기능 설명, CTA까지 구조적으로 완성된 전환 최적화 카피. 크몽 외주 비용(20-50만원) 없이도 프로급 결과물을 얻을 수 있습니다.

## 프롬프트 #6: 톤 변환기

### 프롬프트:
```
다음 글을 [숫자]개의 서로 다른 톤/스타일로 다시 써주세요. 핵심 정보는 동일하게 유지하되 언어, 구조, 어휘를 각 버전에 맞게 조정하세요.

원본 텍스트:
"""
[글 붙여넣기]
"""

만들어야 할 버전:
1. **기업 공식** — 대기업 보고서/보도자료 스타일
2. **캐주얼 대화체** — 동료와 카페에서 대화하듯
3. **학술 격식체** — 학술 논문/학회 발표 스타일
4. **MZ세대 SNS** — 진짜 감 있는, 공감되는 표현 (오글거리지 않게)
5. **스토리텔링/내러티브** — "상상해보세요..." 또는 인물 등장으로 시작

각 버전에 대해 추가로 알려주세요:
- 이 톤의 최적 사용처
- 가장 잘 맞는 플랫폼
- 이 톤이 여기서 효과적인 이유
```

### 사용 예시:
200자 분량의 "클라우드 컴퓨팅의 이점" 설명 단락.

### 예상 결과:
동일한 내용의 5가지 완전히 다른 버전. 네이버 블로그용, 사내 보고서용, 인스타그램용 등 같은 메시지를 다른 채널에 맞춰 전달해야 할 때 핵심 도구.

## 프롬프트 #7: 헤드라인 팩토리

### 프롬프트:
```
다음 콘텐츠에 대해 심리적 트리거별로 정리된 30개 헤드라인 옵션을 생성해주세요:

콘텐츠 주제: [주제]
타겟 독자: [독자층]
콘텐츠 유형: [블로그 글 / 이메일 / 광고 / 영상 / 랜딩페이지]
핵심 혜택: [주요 혜택]

각 카테고리별 5개씩 생성:

1. **호기심 갭** — 더 알고 싶게 만들기
2. **구체적 숫자** — 구체적이고 신뢰성 있는 주장
3. **실용/방법론** — 명확한 가치 약속
4. **역발상/통념 파괴** — 기존 상식에 도전
5. **사회적 증거/권위** — 신뢰 활용
6. **FOMO(놓칠까봐)** — 긴급성과 희소성

각 헤드라인에 대해:
- 예상 클릭률 잠재력 (1-10점)
- 가장 적합한 플랫폼
- 낚시성이 느껴지면 표시 (피해야 할 것)

마지막으로 TOP 3를 선정하고 이유를 설명해주세요.
```

### 사용 예시:
- **주제:** 직장인을 위한 시간 관리 기법
- **독자:** 25-40세 사무직 직장인
- **유형:** 블로그 글
- **혜택:** 하루 2시간 확보

### 예상 결과:
심리적 트리거별로 정리된 30개 헤드라인 + 평점 + 플랫폼 추천. 브런치, 네이버 블로그, 유튜브 썸네일 등 어디든 바로 적용 가능. 수 시간의 브레인스토밍과 A/B 테스트 추측을 없앱니다.

## 프롬프트 #8: 문법·스타일 교정기

### 프롬프트:
```
다음 글을 교정해주세요. 각 수정 사항은 이 형식을 사용하세요:

❌ 원문: [잘못된 텍스트]
✅ 수정: [올바른 텍스트]
📝 규칙: [간략한 문법/스타일 규칙 설명]

점검 카테고리:
1. 문법 오류 (주어-서술어 호응, 시제 일관성, 조사 사용 등)
2. 맞춤법 및 띄어쓰기
3. 오탈자
4. 스타일 문제 (장황함, 피동형 남용, 지시어 모호 등)
5. 서식 일관성

   - 함께 움직이는 것은?
   - ⚠️ 상관관계 ≠ 인과관계 경고

6. **시각화 추천**
   - 이 인사이트를 가장 잘 보여줄 차트는?
   - 각 축에 무엇을 놓을지

7. **다음 질문**
   - 추가로 필요한 데이터는?
   - 다음에 검증해야 할 가설은?
```

### 사용 예시:
3개월치 웹사이트 트래픽 데이터 (날짜, 페이지뷰, 이탈률, 전환율, 트래픽 소스)를 붙여넣으세요.

### 예상 결과:

## 더 좋은 결과를 얻는 방법

### 1. 프롬프트 체이닝
한 번에 모든 것을 요구하지 마세요. 이 프롬프트들을 출발점으로 삼고 후속 요청을 하세요:
- "톤을 좀 더 캐주얼하게 바꿔줘"
- "3번 포인트를 더 자세히 풀어줘"
- "B안과 비슷한 옵션을 5개 더 줘"
- "이걸 링크드인 대신 인스타그램용으로 바꿔줘"

### 2. 맥락을 충분히 제공하세요
맥락이 많을수록 결과물이 좋아집니다:
- ❌ "AI에 대한 블로그 글 써줘"
- ✅ "AI 생산성 도구에 대한 블로그 글을 써줘. 독자: AI에 회의적이지만 호기심은 있는 비기술직 중소기업 사장님. 톤: 친근한 전문가. 길이: 2,000자."

### 3. 역할 부여를 활용하세요
"당신은 [전문가 역할]입니다"로 시작하면 결과 품질이 일관되게 향상됩니다. 이 팩의 모든 프롬프트가 이 기법을 사용합니다.

### 4. 재생성보다 반복 개선
결과물이 70% 맞으면, 처음부터 다시 하지 말고 30%에 대한 구체적 피드백을 주세요:
- "구조는 좋은데 예시를 SaaS 맥락으로 바꿔줘"
- "1-3번은 좋아. 4번이 너무 일반적이니 더 실행 가능한 것으로 바꿔줘"

### 5. 최고의 결과물을 템플릿으로 저장하세요
완벽한 결과물이 나오면 저장하세요. 다음에 예시로 제시하면 됩니다:
- "이 스타일로 써줘: [예시 붙여넣기]"
