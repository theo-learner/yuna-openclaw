### 1.2 한줄 설명

> **"아이가 일상에서 가장 많이 마주치는 글자부터 배우는, AI 맞춤 8주 한글 워크북"**

### 1.3 핵심 차별화: 빈도 기반 학습 순서

| 구분 | 기존 방식 (한글이야호, 핀덴 등) | 우리 방식 (빈도 기반) |
|------|-------------------------------|---------------------|
| **학습 순서** | 훈민정음 창제 원리 또는 자모 순서 (ㄱ→ㄴ→ㄷ) | 실제 사용 빈도 순서 (ㅇ→ㄴ→ㄱ→ㅅ→ㄷ) |
| **근거** | 언어학적 체계성 | 코퍼스 빈도 분석 + 아동 환경 노출 빈도 |
| **효과** | 체계적이지만 초기 동기부여 약함 | 일상에서 바로 "읽을 수 있는" 경험 → 동기 폭발 |
| **맞춤화** | 동일 순서 일괄 제공 | AI가 아이 수준·관심사에 따라 순서·속도 조절 |

**핵심 가치 제안**: 아이가 마트 간판, 동화책 제목, 과자 이름에서 "엄마 이거 나 읽을 수 있어!"라고 말하는 순간을 **가장 빠르게** 만들어준다.

## 2. 교육 설계

### 2.1 한글 자모 빈도 분석

#### 초성(자음) 빈도 순위

국내 코퍼스 분석 연구(pxd 트위터 60만자 분석, 국립국어원 사용빈도 조사 등)를 종합하면:

|------|------|---------|------|

| 4 | ㅈ | ~9% | |
| 5 | ㄷ | ~8% | |
| 6 | ㄴ | ~7% | |

| 8 | ㅁ | ~6% | |
| 9 | ㅂ | ~5% | |
| 10 | ㄹ | ~4% | |

|------|------|---------|

| 9 | ㅐ | ~4.1% |

#### 종성(받침) 빈도

- 받침 없는 글자가 전체의 **약 56%** → 초기 학습에서 받침 없는 글자 집중이 효율적
- 받침 있을 때 순위: ㄴ(32.4%) → ㄹ(22.4%) → ㅇ(12.4%) → ㄱ(9.1%) → ㅁ(6.6%)

#### 고빈도 음절 (아이 일상 환경 기준)

학술 연구 + 아동 동화/그림책/간판/식품 패키지에서 가장 자주 등장하는 음절:

| 순위 | 글자 | 출현 맥락 |
|------|------|----------|
| 1 | **하** | "-하다" 동사, 하나, 하늘 |
| 2 | **이** | 조사 "이", 이름, 이거 |
| 3 | **가** | 조사 "가", 가다, 가게 |
| 4 | **나** | 나, 나무, 나비 |
| 5 | **아** | 아빠, 아이, 아기 |
| 6 | **마** | 엄마, 마트, 마시다 |
| 7 | **다** | "-다" 어미, 다리 |
| 8 | **사** | 사과, 사랑 |
| 9 | **기** | 비행기, 기차, 기린 |
| 10 | **에** | 조사 "에", 에어컨 |
| 11 | **는** | 조사 "는" |
| 12 | **을** | 조사 "을" |
| 13 | **우** | 우유, 우리, 우산 |
| 14 | **바** | 바나나, 바다, 바람 |
| 15 | **고** | "-고", 고양이 |

### 2.2 8주 커리큘럼 설계

> **설계 원칙**: 받침 없는 고빈도 글자 → 받침 있는 고빈도 글자 → 단어 → 문장 → 이야기

#### 📘 Week 1–2: "나도 읽을 수 있어!" (고빈도 받침 없는 글자)

**목표**: 받침 없는 고빈도 글자 20개를 보고 소리 낼 수 있다

| 주차 | 학습 글자 | 핵심 단어 | 활동 유형 |
|------|----------|----------|----------|
| **1주** | 아, 이, 가, 나, 다, 마, 하, 바, 사, 자 | 아빠, 나비, 바다, 마마, 사자 | 🎨 글자 색칠하기, ✏️ 큰 글자 따라쓰기, 🃏 글자-그림 매칭 카드 |
| **2주** | 오, 우, 고, 기, 무, 두, 보, 소, 토, 호 | 우유, 고기, 무지개, 토끼, 호두 | 🧩 글자 미로 찾기, 🎲 글자 빙고, 📸 집안에서 글자 찾기 사진 미션 |

**부모 가이드**: "거리 간판, 과자 포장지에서 이번 주 배운 글자를 찾아보세요. 찾을 때마다 '와 읽었다!' 하고 크게 칭찬해주세요."

---

#### 📗 Week 3–4: "이건 내 이름이야!" (받침 있는 글자 + 단어 읽기)

**목표**: 고빈도 받침 글자(ㄴ, ㄹ, ㅇ)를 이해하고, 2~3글자 단어를 읽을 수 있다

| 주차 | 학습 내용 | 핵심 단어 | 활동 유형 |
|------|----------|----------|----------|
| **3주** | 받침 ㄴ: 간, 난, 만, 반, 산, 은, 인 | 바나나, 산, 반지, 인사 | ✏️ 받침 채워 넣기, 🎨 단어 + 그림 연결, 🏷️ 이름표 만들기 |
| **4주** | 받침 ㄹ, ㅇ: 달, 물, 강, 공, 빵 | 달, 물, 공, 강아지 | 🃏 단어 카드 게임, 🧩 단어 퍼즐 맞추기, 🎭 단어로 문장 만들기 놀이 |

**부모 가이드**: "아이 이름에 들어간 글자를 특별히 다뤄주세요. '내 이름을 쓸 수 있다'는 강력한 동기부여가 됩니다."

---

#### 📙 Week 5–6: "문장을 읽어요!" (문장 읽기 시작)

**목표**: 3~5단어로 된 짧은 문장을 소리 내어 읽을 수 있다

| 주차 | 학습 내용 | 핵심 문장 예시 | 활동 유형 |
|------|----------|-------------|----------|
| **5주** | 조사(은/는, 이/가, 을/를) + 문장 구조 | "나는 사과를 먹어요", "고양이가 자요" | 📝 단어 카드로 문장 조립, 🎨 문장 읽고 그림 그리기, 🏷️ 문장 스티커 북 |
| **6주** | 의문문, 감탄문 + 다양한 문장 | "이건 뭐야?", "와! 크다!" | 🎭 역할놀이 대본 읽기, ✏️ 빈칸 채워 문장 완성, 🎲 문장 주사위 게임 |

**부모 가이드**: "동화책을 읽어줄 때 간단한 문장이 나오면 아이에게 읽어보라고 해보세요. 못 읽어도 괜찮다는 분위기가 중요합니다."

---

#### 📕 Week 7–8: "나 혼자 읽는다!" (짧은 이야기 읽기)

**목표**: 4~6줄 분량의 짧은 이야기를 스스로 읽고 내용을 말할 수 있다

| 주차 | 학습 내용 | 활동 유형 |
|------|----------|----------|
| **7주** | 3~4줄 짧은 이야기 읽기 (그림 힌트 있음) | 📖 미니 동화책 읽기, 🎨 이야기 순서 그림 맞추기, ✏️ 나만의 문장 쓰기 |
| **8주** | 5~6줄 이야기 읽기 (그림 힌트 최소화) + 복습 | 📖 졸업 동화책 읽기, 🏆 "한글 마스터" 수료증, 📝 내가 쓰는 짧은 편지 |

**부모 가이드**: "8주차 마지막 날, 아이가 할머니/할아버지에게 짧은 편지를 읽어드리는 이벤트를 추천합니다. 최고의 성취감입니다."

## 3. AI 맞춤 요소

### 3.1 초기 수준 진단

워크북 시작 전 **5분 간단 진단** (부모 체크리스트 + 아이 인터랙션):

| 레벨 | 이름 | 기준 | 시작 주차 |
|------|------|------|----------|
| **L0** | 🌱 씨앗 | 한글에 전혀 관심 없음. 글자를 그림으로 인식 | Week 0 (사전 준비 주) |
| **L1** | 🌿 새싹 | 자음 일부 알고 있음 (ㄱ,ㄴ,ㄷ 정도) | Week 1 |
| **L2** | 🌳 나무 | 받침 없는 글자 읽을 수 있음 (가, 나, 다) | Week 3 |
| **L3** | 🌻 꽃 | 간단한 단어 읽을 수 있음 (사과, 나비) | Week 5 |

### 3.2 적응형 난이도 조절

```
[주차 완료] → [달성도 체크 (부모 보고 + 퀴즈)]
                    ↓
              달성도 ≥ 80%  → 다음 주차 정상 진행
              달성도 50~79% → 보충 활동지 추가 + 다음 주차 난이도 약간 낮춤
              달성도 < 50%  → 해당 주차 반복 (다른 테마/활동으로 변주)
```

### 3.3 관심 주제 반영 (테마 맞춤)

아이의 관심사를 선택하면 **동일한 학습 목표**를 다른 테마 단어로 제공:

| 관심 주제 | Week 1 예시 단어 | Week 5 예시 문장 |
|----------|----------------|----------------|
| 🦕 공룡 | 티라노, 사우루스, 고비 사막 → 티, 사, 고 | "공룡이 크게 울어요" |
| 🚗 자동차 | 버스, 택시, 기차 → 버, 택, 기 | "빨간 버스가 달려요" |
| 🐱 동물 | 고양이, 토끼, 기린 → 고, 토, 기 | "고양이가 우유를 먹어요" |
| 🧁 음식 | 사과, 바나나, 우유 → 사, 바, 우 | "맛있는 사과를 먹어요" |
| 👸 공주/왕자 | 성, 왕, 공주 → 성, 왕, 공 | "공주가 노래를 불러요" |

### 3.4 AI 기술 활용 포인트

| 기능 | AI 역할 | 구현 방식 |
|------|--------|----------|
| **진단** | 부모 응답 기반 레벨 분류 | 규칙 기반 + 간단한 분류 모델 |

## 4. 제품 형태

### 4.1 디지털 PDF 워크북

- **형식**: A4 사이즈 인쇄용 PDF (가정용 프린터 최적화)
- **분량**: 주당 12~16페이지 (하루 2페이지, 주 5~6일)
- **구성**:
  - 📖 학습 페이지 (글자 인식, 따라쓰기)
  - 🎮 놀이 활동 페이지 (색칠, 미로, 스티커, 카드게임)
  - ✅ 체크리스트 (부모용 달성도 확인)
  - 🏆 주간 완료 스티커판

### 4.2 배포 방식

| 옵션 | 설명 | 장점 |
|------|------|------|
| **A. 한 번에 전체 제공** | 결제 즉시 8주분 PDF 다운로드 | 단순한 UX, 즉시 만족 |
| **B. 주차별 순차 제공** | 매주 월요일 새 워크북 이메일/앱 알림 | 기대감, 적응형 조절 가능 (🌟 **추천**) |
| **C. 하이브리드** | 전체 PDF + 주차별 맞춤 보충자료 | 둘 다 만족 |

> **추천: B안** — 주차별 순차 제공. AI 맞춤 조절과 시너지가 크고, 매주 "새 워크북이 왔어!" 기대감이 지속적 동기부여.

### 4.3 부모 가이드

각 주차 워크북 앞 2페이지에 포함:

- 📋 **이번 주 학습 목표** (아이와 함께 읽기)
- 💡 **이렇게 해주세요** (구체적 코칭 팁 3가지)
- ⚠️ **이건 피해주세요** (과도한 반복, 역압, 비교 금지)
- 🎯 **생활 속 미션** (마트에서 "사과" 찾기 등)
- ✅ **달성도 체크리스트** (다음 주 AI 조절에 반영)

## 7. PrintPlay / AI 성장 트래커와의 시너지

### 7.1 PrintPlay 엔진 연계

| PrintPlay 기능 | 한글 워크북 활용 |
|---------------|----------------|
| **PDF 템플릿 생성** | 주차별 워크시트 자동 레이아웃 |
| **동적 콘텐츠 삽입** | 아이 이름, 관심 주제, 학습 글자를 워크시트에 반영 |
| **일러스트 배치** | 글자별 연상 이미지 자동 배치 |
| **인쇄 최적화** | A4, Letter, 양면/단면 옵션 |
| **다국어 확장** | 향후 영어 파닉스 워크북으로 확장 가능 |

> **핵심**: PrintPlay의 PDF 생성 엔진을 재활용하면 **개발 비용 최소화 + 빠른 출시** 가능

### 7.2 AI 성장 트래커 연계

| 트래커 기능 | 한글 워크북 활용 |
|-----------|----------------|
| **발달 이정표 추적** | 한글 학습 진도를 발달 타임라인에 통합 |
| **주간 리포트** | 한글 학습 달성도 + 다음 주 추천 포함 |
| **종합 대시보드** | 인지·언어·신체 발달 중 "언어" 영역의 핵심 지표로 활용 |
| **데이터 축적** | 수천 명 학습 데이터 → 최적 커리큘럼 개선에 활용 |
