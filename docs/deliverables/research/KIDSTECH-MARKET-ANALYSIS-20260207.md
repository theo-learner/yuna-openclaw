## 7. TAM/SAM/SOM 추정 (AI 성장 트래커 기준)

### 정의
- **제품 컨셉**: AI 기반 아동 성장/발달 추적 + 습관 형성 앱 (0~7세)
- **수익모델**: 프리미엄 구독 (월 9,900~19,900원), 추가 콘텐츠 IAP

### TAM (Total Addressable Market) — 전체 도달 가능 시장
```
국내 키즈산업 중 교육+헬스케어+디지털 비중 (~15%)
= 64조 × 15% = 약 9.6조원

또는 글로벌 관점:
국내 에듀테크 시장 ~10조원 중 영유아(0~7세) 비중 ~20% = 약 2조원
```
**→ TAM: 약 2~9.6조원** (좁은 범위 기준 2조원)

### SAM (Serviceable Addressable Market) — 실제 접근 가능 시장
```
0~7세 영유아 보유 가구수: ~160만명 ÷ 1.2(형제 보정) ≈ 133만 가구
디지털 육아앱 사용 비율: ~60%
= 133만 × 60% = ~80만 가구

연간 ARPU 기준:
80만 가구 × 월 14,900원 × 12개월 = 약 1.43조원
```
**→ SAM: 약 1,400~1,500억원** (유료 전환율 10% 적용 시)

### SOM (Serviceable Obtainable Market) — 3년 내 현실적 획득 시장
```
런칭 3년차 목표:
- DAU 5만명, MAU 15만명
- 유료 전환율: 8~10%
- 유료 구독자: 1.2~1.5만명
- ARPU: 월 14,900원

연 매출 = 1.3만 × 14,900원 × 12개월 ≈ 23억원
```
**→ SOM: 약 20~30억원** (3년차 기준)

### 시장 크기 요약
| 구분 | 규모 | 산출 근거 |
|------|------|-----------|
| TAM | ~2조원 | 국내 영유아 에듀테크 시장 |
| SAM | ~1,500억원 | 디지털 육아앱 유료 시장 |
| SOM | ~20~30억원 | 3년차 현실적 매출 |

## 8. Bull/Bear 시나리오

### 🐂 Bull 시나리오 (낙관)
| 항목 | 전망 |
|------|------|
| **시장** | 키즈테크 연 15%+ 성장, 키즈앱 CAGR 26%+ |
| **출산율** | 2025년 0.79 → 2027년 0.8+ 반등 (정부 정책 효과) |
| **정책** | 부모급여 확대, AI 디지털교과서 도입으로 에듀테크 수요 폭발 |
| **경쟁** | AI 차별화로 기존 앱(베이비빌리, 키즈노트) 대비 우위 확보 |
| **수익** | 3년차 MAU 20만+, 구독 매출 40억+, 시리즈A 100억+ 투자 유치 |
| **확장** | 습관/성장 데이터 → 건강기능식품/교육 콘텐츠 커머스 확장 |
| **밸류에이션** | 시리즈A 기준 500~800억 기업가치 |

- AI 개인화 성장 리포트가 맘카페에서 바이럴
- 소아과/육아 인플루언서 파트너십
- B2B(어린이집/유치원) 채널 확보
- 일본/동남아 등 저출산 국가 글로벌 확장
