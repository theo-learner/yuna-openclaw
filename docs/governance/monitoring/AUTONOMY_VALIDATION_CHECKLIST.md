# Autonomy Validation Checklist (OpenClaw General)

목적: "정상은 무응답(NO_REPLY), 예외만 보고" 원칙이 실제 운영에서 지켜지는지 매일 검증한다.

## A. 정량 지표 (Daily)
- NO_REPLY 비율: ____ % (목표: >= 70%)
- 비허용 보고 비율(승인/리스크/마일스톤 외): ____ % (목표: <= 5%)
- 중복 알림 건수: ____ 건 (목표: 0~1)
- 에러 원문/민감정보 노출: ____ 건 (목표: 0)

## B. 시나리오 테스트 (주 2회)
1) 정상 작업 입력 -> NO_REPLY 확인
2) 승인 필요 작업 입력 -> 승인 요청 보고 확인
3) 실패 반복 입력 -> 리스크 보고 + 에스컬레이션 확인
4) 마일스톤 완료 입력 -> 완료 보고 + 증빙 링크 확인

## C. 보고 포맷 준수
- 형식: [유형] [영향] [필요결정] [권장안] [증빙링크]
- 필수 항목 누락 0건

## D. 합격 기준
- A 항목 목표치 달성 + B 시나리오 통과 + C 포맷 누락 0

## E. 운영 메모
- 정상 상태: NO_REPLY
- 예외 상태만 Theo DM 보고
- 회사 채널에는 에러 원문/스택트레이스/민감정보 금지
